TermuxHiveBear: El Corazón donde Nace la Manada

Inferencia Local & Distribuidas con Candle (Rust)

Motor de inferencia 100% en Rust sin dependencias C++ pesadas. Ejecuta modelos GGUF directamente en tu procesador o GPU, o divide la carga de inferencia entre múltiples nodos P2P cuando necesites más potencia.

# Carga nativa sin dependencias externas
hivebear run qwen2.5-coder:7b --local-first --gpu-candle

Nodos Móviles Nativos (Termux / APK)

🛡️

Bypass NAT Cifrado & Conexión Directa QUIC

Conecta nodos sin importar dónde estén. Protocolo agujereado de puertos STUN/TURN automático para atravesar routers domésticos y CGNAT sin abrir puertos manualmente. Todos los datos viajan cifrados punto a punto.

TLS 1.3 Peer-to-Peer Tunnel → [ Node A ] ⚡───(QUIC Stream)───⚡ [ Node B ]

¿Por qué HiveBear es Diferente?

Comparación frente a proveedores de API centralizados y ejecutores locales tradicionales.

Característica 🐻 HiveBear P2P (Termux & Desktop) APIs Centralizadas (OpenAI/Anthropic) Local Tradicional (Ollama)
Privacidad de Datos ✓ Cifrado E2EE QUIC ✗ Pasan por servidores centralizados ✓ Local
Inferencia Distribuidas ✓ Múltiples nodos P2P ✗ No (Cloud cerrado) ✗ Solo hardware local
Costo de Uso ✓ Gratuito (Sistema Karma) ✗ Pago por Token / Suscripción ✓ Gratuito
Soporte Móvil Nativo / Termux ✓ Termux Android Repo Oficial + APK ✗ Solo cliente Web/API ✗ Complejo de instalar
